# Core Data API — payload `platform.core_record` v1

`database-schema-v1.md` chốt cột SQL. File này chốt **ý nghĩa `kind/source_type/source_id/payload`** để P03, P08, P12 viết cùng contract. Mỗi payload có `schemaVersion:1` (integer), JSON Schema ở `contracts/core-records/<kind>.schema.json`, `additionalProperties:false`; `checksum_hex` là SHA-256 JCS UTF-8 của payload, server tính. `built_at`, `created_at`, `updated_at`, `version`, `actor` do server quản; client không gửi. `source_type/source_id` là khóa idempotency; cùng khóa + cùng hash trả record hiện có, khác hash cần `If-Match` và use case cho phép update, nếu không 409.

| Kind | `source_type`/`source_id` | Payload required | Writer/transition |
| --- | --- | --- | --- |
| `evidence_metadata` | `evidence`/UUID mới do server cấp | `{schemaVersion,ownerType:'document'|'batch'|'trace_event',ownerId:uuid,attachmentId:uuid,title:string,description?:string,occurredAt?:UTC}` | User có quyền trên owner tạo/sửa với `If-Match`; attachment phải `clean` và visibility không vượt policy owner; delete/revoke qua action có audit, không xóa chứng cứ khỏi history |
| `trace_projection` | `lot`/local `catalog.batch.id` UUID | `{schemaVersion,originLot:{issuerInstanceId,lotId},sourceEventIds:uuid[],nodes:[{eventId,issuerInstanceId,type,occurredAt,verificationState}],edges:[{fromEventId,toEventId?,missingRef?,relation}],transformVersion,asOf}` | Trace projector service upsert version/`If-Match`; rebuild deterministic từ trace source; public chỉ qua `passport_projection` allowlist, không expose raw graph trong QR |
| `ot_reading` | `simulator`/`<deviceId>:<readingId>` | `{schemaVersion,deviceId,readingId,batchId:uuid,metric:'temperature_c',value:decimalString,unit:'C',observedAt:UTC,qualityState:'accepted'|'stale',simulated:true}` | Chỉ simulator service identity P12; append-only. Device ID nằm trong allowlist versioned `deploy/ot/device-registry.example.json` với batch/warehouse mapping; secret thực qua secret ref ngoài Git. Unknown device → reject + security audit; stale reading lưu qualityState `stale` nhưng không tự nâng chất lượng lô |
| `archive_manifest` | `archive_partition`/`<instanceId>/<year>/<month>/<eventType>/<runId>` | `{schemaVersion,objectKey,sha256Hex,recordCount,firstOccurredAt,lastOccurredAt,sourceMinId,sourceMaxId,exportedAt,checkpoint,format:'jsonl'}` | Chỉ archive worker P12; append-only. Object ở storage private, key namespace instance; record count/checksum đối chiếu khi restore, manifest không chứa secret/raw PII |

`trace_projection.sourceEventIds` trỏ local `traceability.trace_event.id`; graph remote dùng `issuerInstanceId` + external event ID trong node summary, không giả FK xuyên instance. `archive_manifest` lưu checkpoint sau khi object đã upload/checksum, và source outbox/event có thể replay; cùng `source_id` + hash idempotent. `ot_reading` cùng `deviceId:readingId` + hash idempotent, hash khác trả 409/audit. `evidence_metadata` link tới attachment clean hiện tồn tại và authorization check **trước** khi ghi record; core API recheck khi GET/download.

P03 tạo core API endpoint/schema cho `evidence_metadata` và generic **service-only** kind route, nhưng không nhận JSON tự do ngoài schema. P08 thêm writer/projector `trace_projection`; P12 thêm `ot_reading`/`archive_manifest`. Contract tests phải có valid, missing/extra field, wrong role/owner, duplicate same/different hash, version conflict, file pending, stale/unknown device và restore/checksum; mọi dữ liệu demo có `simulated:true` khi là OT giả lập.
